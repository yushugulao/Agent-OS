# Agent-OS 文档目录

本目录保存 uCore 分支的正式交付文档。文档目标是让评委能够直接理解系统实现、接口、验证方式、测试覆盖和最终演示场景。

建议阅读顺序：

1. `design.md`：整体架构和关键设计。
2. `api.md`：系统调用、数据结构和工具语义。
3. `verification.md`：如何构建、运行和判断通过。
4. `testing-details.md`：每个测试程序具体验证什么。
5. `demo-script.md`：最终演示的推荐讲解流程。
6. `requirements-traceability.md`：赛题任务与当前实现的对应关系。
7. `test-record.md`：最近一次可复现测试输出记录。
