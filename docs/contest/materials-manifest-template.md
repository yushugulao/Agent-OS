## 生成哈希

Linux、WSL 或 MSYS2：

```bash
sha256sum <file>
wc -c < <file>
```

Windows PowerShell：

```powershell
Get-FileHash -Algorithm SHA256 -LiteralPath <file>
(Get-Item -LiteralPath <file>).Length
```

Git 身份：

```bash
git rev-parse HEAD
git status --short
git tag --points-at HEAD
```
