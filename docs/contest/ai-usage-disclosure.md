# AI 工具使用披露

本项目的系统运行时与开发辅助工具彼此独立。AgentOS 内核不保存云端密钥，默认演示和正式验收均可在无网络环境运行。

开发过程中使用了 OpenAI Codex 编程智能体，主要用于仓库分析、方案讨论、代码与测试修改、审查、文档整理和命令执行。AI 生成内容只有在进入 Git 变更、通过人工取舍并接受与其他代码相同的编译、QEMU 和 Host 合同检查后，才成为项目内容。会话文本、访问令牌、API 密钥和本机私有配置不进入仓库。

本仓库可能包含兼容第三方模型服务的用户态适配入口。适配器存在不表示相应模型参与了开发，也不把模型服务纳入内核可信计算基。

AI 输出不作为正确性或性能证据。发布结论必须来自冻结提交对应的源码、原始 Guest/Host 日志、可重放统计和正式 evidence bundle；公式生成数据、硬编码成功文本和历史运行结果不能替代本轮观测。架构取舍、赛题符合性、许可证核验和最终陈述由参赛队负责。
