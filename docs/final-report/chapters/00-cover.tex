本文把四种证据严格分开：静态合同说明接口和边界存在；cross build 说明内核与
Guest 能以目标 ABI 编译链接；QEMU Guest 场景说明实际运行路径成立；配对性能数据
说明给定负载、样本和口径下的观察结果。任何一种证据都不替代另外三种。

文中“模型调用”只在真实 provider 或同路径 replay 实际完成时成立；
“性能改善”只引用冻结 one-shot 数据或明确的竞赛基准，不从日志热闹程度、
observer 刷新速度或静态代码形状反推。
